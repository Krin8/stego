# Frozen-feature CT improvements

Locked implementation details: [PROTOCOL.md](PROTOCOL.md). All outputs under audit/improve; CPU only. No head training, installation, project-source changes, derivative/cache regeneration, or existing checkpoint modifications. Seeds0/1/2, K8, uncentered normalized final patch tokens, all2,341 CT slices and20 patients. All patches participate in Lloyd KMeans (n_init3, max_iter100, tol1e-4); no patch subsampling.

## Evaluation and label use

Primary resolution is224×224, preserving FINAL_BASELINE; supplementary native resolution is512×512. Mapping is fitted on the other19 patients, then scored on the held-out patient, independently per scoring resolution. Strict majority and exhaustive256-subset optimal mapping both reported. Outside-crop pixels are forced background and their missed liver pixels remain in the denominator when fitting/scoring mappings. Patient pixels are pooled before IoU/Dice; seed scores averaged within patient, then equally weighted patient mean/sample-SD/min/max. No best-seed selection.

**Labels:** extraction/cropping/clustering/temperature/filter parameters use no ground-truth annotations. LOPO mapping and scoring use labels on separate patients. Grid ceilings directly use all labels. Largest-liver figure slices use validation labels; the four original fixed slices are label-blind patient midpoints. B4/B5 parent selection and final best-variant selection use cohort LOPO scores and are exploratory. This is transductive clustering: held-out images are included in fitting, held-out labels excluded from their mappings.

For B4/B5, “optimal/majority” refers to the parent hard-cluster mapping fitted on the other19 patients. Mappings are inherited and not reoptimized after smoothing/component filtering. B4 soft-only and soft+guided are separately reported; B5 2D and3D are separate filters applied to the parent hard map.

## Step0: annotation-derived grid approximations

Producer: `ceiling.py` → `ceiling.json`. Hard cells use majority (>0.5), means use bilinear upsampling (align_corners=False) then threshold>=0.5. All cells use native512 pixels, with explicit nonoverlapping integer-bin boundaries. Primary results then use the same nearest224 mask transform. These are diagnostic constructions, not guaranteed mathematical upper bounds on every possible coarse predictor. These uncropped-frame grids are also not direct upper bounds for the body-cropped/tiled variants.

Gap explained = (100 − ceiling mean IoU)/(100 − exact B0 mean IoU), for224 only. It measures the residual gap attributable to that representation/reconstruction under this diagnostic; it is not a causal decomposition of the learned model error.

## Implementation evidence and limits

B0 refitting/scoring reproduced every original per-patient IoU/Dice exactly for all3 seeds (`B0_s*_scores.json`: baseline_max_patient_metric_difference=0). `prepare.py` → `support.json` confirms existing dynamic positional interpolation at336/448 with21²/28² feature grids. Actual installed positional embedding implementation saved as `position_embedding_source.txt`. Body crop has zero empty-body fallbacks (`metadata.json`); crop boundaries and physical positions saved per sample. Native inverse-crop maps include zero-padding and force out-of-crop background.

B0 primary hard assignments go directly14→224 to exactly reproduce FINAL_BASELINE. Crop variants are first restored to512, then sampled with the same nearest224 mask transform; native results expose the frame-level comparison. Per-seed raw numbers and cluster mappings are preserved in JSON.

Extraction: `extract.py`, frozen project BiomedCLIP extractor in eval/no-grad; B3 averages normalized-block tokens over9 overlapping tiles before L2. `fit.py` uses a disposable disk-backed working matrix with copy_x=False to bound RAM; statistical KMeans settings unchanged. This does not alter existing features or pipeline caches. B4 temperature is derived from unlabeled distance gaps (recorded in each fit JSON), not adjusted to labels. Guided filter is implemented with installed scipy uniform filters, radius8/epsilon0.01. 3D component filtering uses6-connectivity in physically sorted consecutive slices; anisotropic physical spacing is not resampled, and anatomy fragmented across slices may be removed.

Optional B6 uses the locally available DINOv2 ViT-L/14 checkpoint via offline local torch hub, strict weight loading, final LayerNorm patch tokens, CLS excluded,16² at224 and DINO ImageNet mean/std; no download. Its checkpoint/model support is verified by successful extraction, otherwise explicitly UNVERIFIED.

B6 is a pre-declared224-input, body-cropped comparison; it is not a resolution-matched comparison against the448 BiomedCLIP arm and cannot establish universal backbone superiority.

**UNVERIFIED:** external/unseen-cohort generalization; performance on an untouched test set; clinical/native-resolution boundary reliability; other crop thresholds, soft temperatures or filters (not tuned). The cohort is CT-only and already explored. B4/B5 and selected-best scores include selection optimism; LOPO mapping does not remove that outer-selection bias.

Reproduction commands: `commands.txt`. Repository state: `repository_state.json`. Live current-vs-reused feature and synthetic crop checks: `checks.py` → `checks.json`. Final fold/statistic/pixel-count/source-hash validation: `validate.py` → `validation.json`.
