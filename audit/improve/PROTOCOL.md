# Pre-declared implementation details

Recorded before any improvement metrics. CPU only; outputs under audit/improve.

- Seeds 0,1,2; K=8 throughout; all 2,341 slices and all patches; sklearn KMeans Lloyd, n_init=3, max_iter=100, tol=1e-4, as BASELINE. Final normalized patch tokens then L2; no centering. No neural training.
- Primary comparison preserves FINAL_BASELINE's 224×224 masks (user confirmed). Every variant also receives native-frame scoring; no native-frame score is compared directly to the old 224 baseline.
- Patient-wise LOPO mappings: strict majority and exhaustive IoU-optimal subset, fitted on other 19 patients. Scores pool each held-out patient's pixels. Average seeds within patient, then mean/sample-SD/min/max over 20 patients; all seed-level and patient-level results retained.
- B0 is refit on existing verified final-block features. Re-score and compare all 20 patient confusion matrices to FINAL_BASELINE (cluster-permutation invariant mapping metrics).
- B1 body mask: windowed intensity >0.05 (HU >-130), 8-connected largest component, fill holes. Square bounding box expanded 5% on each side; integer-ceil side, centered on bbox; zero pad beyond original frame. Empty-mask fallback is full square frame. No annotation inspection for these choices. Resize to224, RGB replication and existing BiomedCLIP mean/std once.
- B2: same crop, resize336 and448. Use the existing extractor only if its dynamic positional-embedding interpolation succeeds; no source changes.
- B3: body crop resized448, nine224 tiles at offsets0/112/224 in each axis. Extract14×14 final features; stitch into28×28 by equal averaging at overlapping patch locations, then L2. No position interpolation in individual tiles.
- B4 soft weights: exp(-squared_distance/T), T = median(second-nearest distance minus nearest distance)/ln(4), computed from all unlabeled feature vectors, clamped at1e-6. Sum weights of the LOPO-mapped liver clusters; bilinear upsample and inverse crop; threshold >=0.5. Report soft-only and soft+guided. Guided filter on windowed native image: radius8 pixels, epsilon0.01, scipy uniform filters, clamp[0,1], threshold>=0.5. No label-based temperature or filter tuning.
- B5 independent hard-map post-processing arms: largest8-connected component per native slice; largest6-connected component across each patient's physically ordered native slices (no interpolation of slice spacing). Parent is the same B0–B3 parent as B4. Mappings inherited from parent, not refitted after processing.
- User confirmed B4/B5 parent is the B0–B3 variant with highest mean primary224 LOPO optimal IoU averaged over seeds (ties retain earlier listed variant). Both descendants are exploratory because parent selection uses cohort labels. Do not select a seed. The figure uses seed0, the four original fixed validation mid-slices plus each of those four validation patients' largest-liver slice. The final best variant is selected by the same primary score, clearly descriptive; no parameter tuning follows.
- Optional B6 if local DINOv2 weights can load offline: same B1 crop at224, native DINOv2 final normalized patch14 features (16×16), checkpoint's standard ImageNet normalization, L2, same KMeans and LOPO. Secondary and excluded from B4/B5 parent selection.
- Step0: grids14,21,28,56; assign native512 mask pixels to nonoverlapping near-equal cells by integer floor(x*grid/size). Count cell foreground fraction. Hard majority uses >0.5 (ties background); mean-cell field bilinearly upsampled align_corners=False and threshold>=0.5. Evaluate at native and224; report this annotation-derived approximation, not a label-free method or a mathematical bound on all coarse-grid classifiers.
- No parameters above will change after results. Improvements beyond baseline patient SD mean >62.872+2.604=65.476% under primary224 scoring; this is a descriptive heuristic, not a significance test.
